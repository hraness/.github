# Contents

- `profile/README.md` – the public Hraness organization profile.
- `README_GUIDELINES.md` – the shared information architecture and review
  contract for Hraness repository READMEs and their website projections.
- `.agents/skills/` – portable repository orchestration skills.

# Guidelines

- Keep this repository public, self-contained, and free of private repository
  names, paths, credentials, provider operations, or publication mechanics.
- Treat `README_GUIDELINES.md` as the canonical cross-repository README
  framework. Change it when recurring evidence warrants a shared rule, then
  adopt the change deliberately in affected repositories.
- Keep the organization profile short. Link to shared guidance instead of
  copying it into `profile/README.md`.
- Write direct public prose with literal sentence-case headings, concrete
  claims, explicit limits, and no hype or decorative filler.
